# Tarot Digital Codex

A structured reference system for studying Tarot through symbolism, numerology, correspondences, psychology, and historical interpretation.

This repository is designed to help readers understand how Tarot functions as a symbolic language — not merely memorize isolated card meanings.

Whether studying the Minor Arcana, Court Cards, Major Arcana, elemental correspondences, or esoteric traditions, this codex aims to provide a clear and organized foundation for deeper study.
