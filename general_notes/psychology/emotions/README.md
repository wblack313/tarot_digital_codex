# Emotional Framework for Tarot

## Joy
- happy
- satisfied
- fulfilled
- euphoric
- triumphant

## Love 

##### (ASPPP ELM)

- Agape — selfless/unconditional love
- Storge — familial affection
- Pragma — enduring practical love
- Philia — friendship/brotherhood
- Philautia — self-love/self-regard
- Eros — passionate/romantic love
- Ludus — playful/flirtatious love
- Mania — obsessive, possessive, addictive love
